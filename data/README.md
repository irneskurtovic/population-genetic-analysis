# Data

This folder contains the input datasets and Python scripts used in the population genetic analysis.

## Input Files

- `chr22_first1000.vcf` — VCF dataset containing a subset of chromosome 22 variants.
- `integrated_call_samples_v3.20130502.ALL.panel` — sample metadata and population assignments.

## Analysis Scripts

- `analyze_population.py` — population variant frequency analysis.
- `population_pca.py` — principal component analysis (PCA).
- `population_fst.py` — pairwise population differentiation using FST.
